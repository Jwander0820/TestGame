## B. P0 風格測試驗收

### 主角

- [ ] 第一眼可辨識為認真的新手勇者。
- [ ] 稍大頭盔、短披風與小圓盾形成穩定剪影。
- [ ] 角色可愛但不顯得幼兒化、愚蠢或刻意搞怪。
- [ ] 側視比例可用於 2D 橫向平台遊戲。
- [ ] 在 480×270 與 360×203 畫面中仍能辨識朝向及動作。
- [ ] 沒有持劍姿勢造成玩家期待攻擊功能。

### 場景

- [ ] 畫面看起來像完整的奇幻冒險，不像測試房或教育教材。
- [ ] 背景、遊戲層、前景與援助層有清楚層級。
- [ ] 安全平台頂面與危險區可在一秒內辨識。
- [ ] 背景不搶走主角、陷阱與落腳點。
- [ ] 素材不是高解析插畫套用像素濾鏡。
- [ ] 沒有模糊、抗鋸齒、過度漸層或不一致像素密度。

### 喜劇演出

- [ ] 援助事件在沒有字幕時仍能大致看懂。
- [ ] 世界角色的反應有準備、動作與收尾，不是物件瞬間出現。
- [ ] 主角先驚訝、後裝鎮定的節奏可讀。
- [ ] 笑點指向遊戲世界的狼狽，不羞辱玩家或主角。
- [ ] 史萊姆彈簧仍保留清楚的落點與移動方向。

## C. 正式資產逐項檢查

- [ ] 每個檔案都能對應 `02-asset-list.md` 的資產 ID。
- [ ] 檔名符合 `04-technical-delivery.md` 的規則。
- [ ] PNG 尺寸、透明背景與色彩模式正確。
- [ ] 沒有白邊、半透明毛邊、JPEG 雜訊或浮水印。
- [ ] spritesheet 每格尺寸一致、順序清楚。
- [ ] 角色腳底基準在動畫各幀間穩定。
- [ ] 動畫附有 FPS、循環與錨點說明。
- [ ] 向左動作可安全鏡像；若不可鏡像，已交付對應方向。
- [ ] Tileset 接縫可平鋪，沒有一像素裂縫或明顯重複錯位。
- [ ] 背景層可依規格水平重複或拼接。
- [ ] 圖像內沒有無法修改的對話、數字或亂碼文字。
- [ ] 原始工作檔包含可理解圖層與動畫時間軸。

## D. 遊戲接入驗收

- [ ] 主角美術與既有碰撞箱對齊，腳部不漂浮或穿入平台。
- [ ] 主角待機、移動、跳躍、下降、死亡與重生切換沒有明顯跳幀。
- [ ] 平台美術沒有誤導實際可站立區域。
- [ ] 陷阱啟用、縮短、收回與休息狀態清楚不同。
- [ ] 援助動畫不遮住玩家下一個必要落點。
- [ ] 鏡頭捲動時背景接縫、視差與前景遮擋正常。
- [ ] 桌面 960×540 畫面可讀。
- [ ] 手機橫向縮放後主角、危險物、落點與字幕仍可讀。
- [ ] 手機直向備援縮放後，核心玩法資訊仍可辨識。
- [ ] 素材接入後沒有明顯閃爍、紋理滲色或平滑模糊。
- [ ] 正式建置的圖像資產預算仍在可接受範圍。

## F. 直接退回修正的情況

- [ ] 角色或場景明顯近似特定既有遊戲資產。
- [ ] 風格轉成 3D、插畫、等角視角或非像素表現。
- [ ] 同一角色在不同動作中服裝、比例或配色改變。
- [ ] 生成圖包含多餘肢體、破碎裝備、無法解釋的物件或亂碼。
- [ ] 背景與地形細節導致手機上無法判讀安全路線。
- [ ] 只交付預覽圖、放大圖或影片，缺少原始像素資產。
- [ ] 素材來源、生成工具或商業授權無法說明。
