## 用途

本資料夾整理可提供給像素美術接案者、外包團隊或圖片生成服務的需求，目的是取得可比較的報價、風格測試與正式遊戲資產。

目前確認的高層方向是：

> 表面是一款明亮、可愛且假正經的奇幻平台冒險；玩家反覆死亡後，世界逐漸維持不了專業形象，並以世界觀內的荒謬事件公開作弊幫助玩家。

本包仍屬草案。除上述方向外，角色服裝、最終色盤、每個動畫的精確幀數及完整五關內容，需在風格測試通過後才定案。不得把草案內容視為已授權的大量正式製作。

## 建議委託方式

### 階段 A：付費風格測試

先委託以下四項，不直接製作整批素材：

1. 主角側面角色設計與三種表情。
2. 第一關 960×540 靜態風格示意圖。
3. 主角待機、移動、跳躍的短動畫測試。
4. 一個「史萊姆從坑裡彈回玩家」的援助事件分鏡或動畫測試。

### 階段 B：垂直切片正式素材

風格測試通過後，依 `02-asset-list.md` 的 P0、P1 項目製作首關素材。每批先交低量預覽，確認比例、輪廓與手機可讀性後，再完成全套動畫及變體。

### 階段 C：完整世界擴充估價

森林首關完成並實際接入遊戲後，再估算其餘森林、城堡、洞窟、火山、魔王場景。此階段只要求可擴充方法與單價，不在第一批直接製作完整五關加 Boss。

## 外包報價應拆分

- 風格測試費用與可修改次數。
- 主角角色設計、動畫及表情的費用。
- Tileset、背景、物件、陷阱、援助角色與 UI 的個別費用。
- 額外動畫幀、尺寸調整、改色與追加變體的單價。
- 原始工作檔、PNG／spritesheet 輸出及商業使用授權是否包含。
- 是否使用生成式 AI、使用的服務，以及人工清稿與像素修整範圍。

## 暫不納入

- 完整五小關與 Boss 的全量正式素材。
- 音樂、音效、配音及影片過場。
- 遊戲 Logo、商店宣傳圖與社群行銷素材。
- 直接修改 Phaser 程式、關卡物理與碰撞設定。
- 仿製任何指定遊戲的角色、場景、構圖或素材。
