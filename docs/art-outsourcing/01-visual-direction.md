# 視覺方向規格：假正經的像素奇幻冒險

- 狀態：外包評估草案
- 建立日期：2026-07-17
- 最後更新：2026-07-17

## 核心視覺敘事

遊戲開場必須先讓玩家相信自己正在玩一款完整、可愛且正統的奇幻平台冒險。森林、遺跡、王城、陷阱與勇者都應有一致且可信的世界觀。

笑點不來自畫面一開始就很潦草，而來自世界在玩家反覆死亡後逐漸失去專業形象：平台生物偷偷靠近、守衛關閉機關、史萊姆自願當彈簧，最後連神明或幕後工作人員都直接介入。

## 風格關鍵詞

- 現代可愛像素風。
- 明亮奇幻冒險。
- 圓潤、大輪廓、低至中等細節。
- 假正經、友善、帶有輕微荒謬感。
- 適合手機瀏覽器縮小觀看。
- 角色表情清楚，動畫短而有喜劇節奏。

## 明確排除

- 兒童教材、作業紙、紅筆批改與教室意象。
- 恐怖、血腥、寫實傷害或令人不適的死亡畫面。
- 過度陰暗、髒亂、末日或厚重寫實奇幻。
- 3D 渲染、黏土模型、等角視角或偽 3D 透視。
- 高解析插畫縮小後假裝像素、模糊邊緣或大量抗鋸齒。
- 以錯誤視窗、Debug 介面或故障效果作為主要笑點。
- 直接模仿既有遊戲的角色比例、關卡構圖、怪物或 UI。

## 主角：非常認真的新手勇者

### 角色定位

主角不是愚笨或故意搞笑的人。他相信自己正在執行正式的勇者任務，態度認真、實力普通；喜劇來自他努力維持英雄形象，但世界不得不替他收拾場面。

### 建議外觀

- 約 32×48 px 的側視遊戲角色，尺寸仍需以實機縮圖驗證。
- 稍微過大的圓頭盔，形成遠距離可辨識的頭部輪廓。
- 短披風與小圓盾，建立方向感與移動節奏。
- 護甲簡單、正式但略微不合身。
- 不在手上持有明顯武器，避免玩家誤以為遊戲提供攻擊操作。
- 可選：木製練習劍固定在背包或腰後，不作為戰鬥暗示。

### 性格動畫

- 待機時挺胸、保持認真，偶爾扶正頭盔。
- 跑步時腿部忙亂，上半身仍努力保持英雄姿態。
- 上升時專注，下降時明顯緊張。
- 落地後快速整理裝備，假裝一切正常。
- 被援助時先驚訝，結束後立刻擺出像是自己完成的姿勢。
- 死亡演出可讓頭盔蓋住臉、裝備鬆開或角色扁掉，但不出現傷口。

## 世界與第一關

首個垂直切片暫定為「王城外圍的新手森林」。它需要像一個真正可完成的小型奇幻關卡，不是純測試房。

### 畫面分層

1. 遠景：王城、山脈、天空與大型雲層，低對比、低細節。
2. 中景：圓潤樹木、遺跡、瞭望塔與灌木，建立奇幻氣氛。
3. 遊戲層：草地、石橋、石柱、木架、坑洞與陷阱，輪廓最清楚。
4. 前景：少量葉片、草叢與石塊，不能遮住主角、危險物或落腳點。
5. 援助層：守衛、史萊姆、神明之手、繩索或臨時橋梁，只在系統介入時搶佔視覺焦點。

### 安全與危險語言

- 安全地形：穩定水平頂面、草皮或淺色石材、清楚接觸邊緣。
- 可移動／有生命平台：保留平台輪廓，加入眼睛或微小呼吸，不影響落點判讀。
- 危險物：尖角、收縮動態與高對比暖色，不只依靠紅色辨識。
- 可互動援助：較明亮、動作幅度較大，出現前後要有可讀的準備動作。

## 援助演出的視覺階段

| 層級 | 視覺表現 | 範例 |
| --- | --- | --- |
| 0 觀察 | 世界維持正常 | 普通死亡、快速重生 |
| 1 吐槽 | 角色或物件短暫露出心虛 | 告示牌冒汗、平台看向玩家 |
| 2 偷偷放水 | 小幅且可見的世界變動 | 石台裝作自然地靠近 |
| 3 公開援助 | 世界角色直接協助 | 史萊姆當彈簧、守衛推木橋 |
| 4 荒謬繞過 | 世界放棄維持正常 | 神明伸手接住、整段陷阱被搬走 |

## 色彩原則

- 第一關以天空藍、森林綠、暖灰石材及少量金黃色為主。
- 主角需從綠色與灰色地形中清楚分離；建議使用偏暖的披風或頭盔裝飾作為識別色。
- 危險色與援助色分離：危險偏橘紅，援助偏明亮金色或魔法青色。
- 單一世界建議控制在約 24–32 個主要顏色；透明度主要用於特效，不用來模糊角色輪廓。
