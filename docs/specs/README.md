## 使用方式

- 「草案」代表內容可供討論，不授權正式實作。
- 使用者確認後，將規格狀態改為「已核准」，並在變更紀錄寫下確認日期與調整內容。
- 原型若需在核准前進行，必須另列明確的技術尖峰範圍，且不得擴張成產品實作。
