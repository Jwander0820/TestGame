# SPEC-0014：史萊姆假睡與背後追擊

- 狀態：已實作、技術通過，待真人試玩
- 建立／更新：2026-09-24
- 授權來源：使用者本日要求繼續堆疊惡意，指定休息的怪物突然動起來。
- 關聯：SPEC-0012、SPEC-0013；延用幾何原型與既有援助。

## 目標與流程

第一招結束後的小怪先攤平假睡，再預告並使出第二招。方塊向右回頭追撞，圓形向前補跳，懲罰引完一招就放心走過的玩家。攻擊固定可重現，不隨機、不無限追蹤。

## 規則

- 方塊：原突進結束後假睡 320ms，起身預告 180ms，480ms 內由 x=180 回衝至 x=396。
- 圓形：原跳躍結束後假睡 320ms，起身預告 160ms，650ms 內向右跳 112px、高 76px。
- 假睡／起身預告無傷害，第二招接觸致死，結束後本次生命不再出招。
- 第二招具有獨立死因，歸入原區段援助；第 3 次揭露後手，第 5／7 次的「奉命休息」永久安全，重生／重載也不能偷襲。
- 第一招與第二招都在重生時重設；保留已發現線索。暫停停止有效遊戲時間。
- 回頭追撞可再跳躲開；圓形補跳可在安全距離等完整兩招，再通過。

## 呈現與輸入

延用方塊／圓形；假睡為暗色攤平、一眼偷看，標示「睡著了？」；起身有「！」；最後休息與援助有不同文字，不用援助色暗示假睡安全。桌面與觸控仍只有左右／跳躍，不新增血量、戰鬥、保存版本、角色物理或援助門檻。

## 驗收與驗證

- 狀態測試涵蓋第一招、假睡、預告、回頭／補跳、最後休息、精確時間邊界與位置連續性。
- 兩個新死因各連續死亡，確認原援助階梯能撤除；暫停與保存重載保持正確。
- 實際 Phaser 零死亡整關、最高援助與終點碰撞回歸；不以狀態測試冒充路線驗證。
- 實際桌面與固定 375×667、橫向尺寸檢視假睡與後手，確認提示不遮主角或下一落點。
- typecheck、測試、build，紀錄至 logs 與 STATUS；真人手感待試玩。

## 非目標

不復活已被援助撤除的小怪，不新增美術資產或執行依賴，不推送／部署／提交。
