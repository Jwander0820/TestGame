# SPEC-0025：第二關安全提示的四次反轉

- 狀態：已實作，技術驗證通過；真人難度感受、美術與實體觸控待驗收
- 負責人：Codex／使用者
- 建立日期：2026-10-07
- 最後更新：2026-10-07
- 關聯：SPEC-0024、SPEC-0002、SPEC-0015、SPEC-0005
- 核准來源：使用者試玩第二關後指出「關卡架構有，但是完全沒有惡意，一次就通關，太嫩」。此指示核准加強第二關陷阱及必要回饋、援助、驗證。

## 問題與價值

初版機關只要停下等一次就能通過，所有安全提示都可信，缺乏學會規律之前被世界擺一道的感覺。保留鐘塔運送線架構，讓到站、洩壓、驗收與終點各有固定後手。初見按正常提示前進容易死亡，知道規律後可以零援助破解。

## 目標與非目標

- 四種明確反轉，不能只縮短既有預告或增加速度。
- 死因分開記錄，沿用三段援助與 21 死乘客通道；已保存最高援助不重新武裝。
- 不改第一關、物理參數、按鍵、v2 保存格式，不增加強制死亡、隨機攻擊、Boss、提交或部署。

## 玩家流程與功能需求

1. **到站閘刀**：載台抵達後亮「到站請下貨」，250ms 後 x790 的卸貨閘落下。立刻跳向對岸會撞閘；先留在載台等完整落下／回收即可過。閘寬 52、高 152，頂面由 78 落到 230；落下 180ms、停留 650ms、回收 500ms。
2. **蒸汽旁管**：主蒸汽停後亮「洩壓完成」。此後玩家走到 x1100 才觸發旁管，300ms 後 x1100..1280、y330..430 噴發 1100ms。向前衝會中招，引出後退到 x1080 左側等噴完可過。
3. **快速出口**：主壓機收完後，玩家越過 x1900 觸發「驗收完成，快速出貨」。350ms 後地面 x1950..2040、y310..430 的封口夾啟動 800ms，同時輸送帶改向右搬運，速度 +300。可在預備期向左撤回，啟動期持續向左抵銷搬運，再等它收完；一般地面行走或急著補跳會被送入夾口。
4. **敲鐘配重**：接近 x2570 即啟動終點鐘的配重，400ms 後 x2680..2780 的配重落下，頂面由 100 到 280、高 70；落下 160ms、停留 550ms、回收 400ms。在 x2630 左側等完整回收後敲鐘可過，也可以跳過落點。鐘正在運轉時以文字標示，回收或退休後才能結算。

## 規則與資料

- 四個死因為 arrival-guillotine、steam-backwash、sorting-recall、bell-counterweight；分別歸屬載台、蒸汽、分揀、分揀的既有 blocker。
- 每命每個後手最多觸發一次，不追蹤或隨機鎖定玩家。落下機關與玩家雙方做前後幀的相對掃碰，避免穿透與時間錯開的誤殺；蒸汽與夾口為固定傷害矩形。
- 第 3 死揭露後手並延長對應預告至 1000ms（旁管）或 1100ms（其餘）；載台原踏板仍增加。第 5 死載台步道解除閘刀，關蒸汽閥解除旁管；停帶取消突加速，封口夾／鐘配重仍可等待。第 7 死對應全部機關退休。
- 已保存的效果 ID 沿用；死亡交易、援助保存與據點不換格式。三段退休或本關 21 死，四個後手立即停用，整線平路只向右不跳即可通關。
- 內容／純狀態／Session／場景／像素呈現分離；重生重設本命計時，保留援助；暫停、失焦、死亡、結算不推進有效時間。

## 介面與輸入

- 鍵盤及觸控仍為左右／跳躍，無新互動鍵。
- 誤導文字屬機關告示；物理落點以閘槽、旁管、封口架與配重鏈可觀察。死後明確吐槽剛才的反轉，援助後告示揭露正確解法。
- 仍使用現有像素色盤與可替換程式圖， reduced motion 關閉裝飾轉動／震動，不隱藏必要預告。回饋不依賴音訊或只有顏色。

## 邊界與失敗情境

- 同幀兩種陷阱只計一次死亡；退休立即中止已預備或正在動作的攻擊。
- 重載據點不要求重過先前機關，鐘塔據點仍可破解配重；援助重載保持解除。
- 低幀率以掃過範圍避免穿透，沿用每幀有效時間上限；無存檔仍可安全開始。

## 驗收條件

- AC-1：初版直覺路線會被到站閘刀殺死；分別略懂前招但照安全提示直走的路線會中旁管、快速出口、配重，各至少一死，死因正確。
- AC-2：實際 Phaser 已知破解路線四個後手都觸發後仍 0 死完成，沒有改位置、保存或機關的作弊。
- AC-3：連續死亡原 3／5／7 階段與 21 死全程不跳仍可完成；停帶不造成向左鍵失效或永久卡死，已有最高援助不再殺人。
- AC-4：後手預備／攻擊中暫停保持玩家與機關位置，恢復接續；據點與援助重載正確。
- AC-5：桌面與 375×667、667×375 實際截圖可見機關、預告、落點及可達的觸控列；真人難度感受與實體觸控單獨待驗收。

## 測試策略及預算

- 純狀態測試涵蓋觸發、時間邊界、每命一次、重設、延長預告、各援助取消與最高援助。
- 瀏覽器增加四條直覺受害路線、已知零死、後手暫停／據點／援助重載；保留原蒸汽、壓機及右走路線。
- 執行 npm.cmd run check、相關 Phaser 幾何、死後重生與首關回歸。截圖保存於 ignored output/playwright。
- 無新增依賴、下載圖像或網路服務；固定數量圖形與線性時間狀態運算。
