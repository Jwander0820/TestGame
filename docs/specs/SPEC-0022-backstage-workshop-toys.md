## 問題與價值

後台目前多為靠近即播放的一次性演出。增加可重玩的彈簧小玩具與回頭監工笑點，讓既有移動、跳躍與朝向直接參與互動。

## 目標與非目標

- 在後台加入可取消蓄力的彈簧台、空中驗收鈴與三次遞進吐槽。
- 史萊姆在玩家看向牠時搬箱，背對或走遠就摸魚，重複觀察有額外反應。
- 打磨地面落牌警示與試玩入口，保持同色盤、像素比例及清楚走道。
- 不修改主線物理、輸入鍵、死亡、援助、保存格式、隱藏入口或結局；不新增正式素材來源。

## 玩家流程與功能需求

### FR-1：彈簧驗收台

後台 x=390 的地板嵌入彈簧踏板。站定 420ms 後自動向上彈；離開或主動跳起會取消蓄力。台上有常駐「站定試彈」及空中鈴形輪廓。發射後必須落地並離開踏板才能重新裝填，不連續彈跳困住玩家。

彈起時角色身體穿過高處驗收鈴，記一次成功；同一發射至多一次，普通步行與地面待機不計。前三次依序顯示「一次通過」「需要複驗」「免驗通過」與關卡鬥嘴，第三次以後仍可玩但不刷對話。離開踏板的空中水平移動可自然錯過鈴，再次嘗試。

### FR-2：回頭監工

玩家在史萊姆 300px 內且面朝牠，牠才搬箱；背對或走遠立即休息。左右兩側皆可觀察，靠近不必停步。連續看著只算一次，背對至少 600ms 才能產生下一次抓包；第三次有額外吐槽。箱子與史萊姆皆為背景，無碰撞。

### FR-3：安全與細節

新狀態僅屬本次房間拜訪，重訪重設；不保存驗收次數。主線維持睡眠，房內機制不新增死亡或修改進度。出口始終可用，轉場仍清除輸入。落牌警示增加箭頭與倒數形狀，落牌命中後取消彈簧蓄力。

## 介面與輸入

- 桌面沿用左右／跳躍；手機沿用三鍵，不新增精準點擊。
- 動態遵守減少動態偏好：保留彈簧必要物理，取消鈴晃動、裝忙晃動與角色壓扁縮放；以文字和靜態位置表示。
- 對話每句至少 3.2 秒，新互動不淹沒當前句子；暫停凍結物理、蓄力、驗收與監工狀態。

## 邊界與失敗情境

- 普通跳躍離台取消蓄力；離台返回可重新蓄力；發射中的長幀不重複計鈴。
- 落地仍站台上不會自動再次發射；走出後可重玩。
- 落牌復位、離場、重訪清除局部狀態；刷新依既有主線據點回復。
- 無存檔或最高援助皆可玩；不使 21 死紅毯路線額外遇險。

## 驗收條件與測試策略

| 情境 | 結果與方法 |
| --- | --- |
| 蓄力、取消、重裝填 | 狀態測試；角色步行離開與跳起皆能取消，一次發射至多一次驗收 |
| 三次試彈 | 實際 Phaser 操作，三次碰鈴、可重玩並零死返回主線通關 |
| 監工、背對、再看 | 狀態測試及實際路線，兩側朝向正確、站著不刷抓包 |
| 暫停與重訪 | 蓄力及飛行中暫停不偷跑；重訪重設、發現仍一筆 |
| 主線回歸 | 原落牌命中、重載、零死、21 死只向右與主線時間／進度隔離 |
| 視覺及觸控 | 桌面、375×667、667×375 正式外框截圖；觸控三鍵可達，實體手感另記待驗 |

## 效能與資產

只使用現有色盤的原創程式像素道具，無新套件、網路、音效或保存欄位。單一踏板、鈴與箱子，狀態每幀常數成本。
