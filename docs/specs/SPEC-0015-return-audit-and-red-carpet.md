# SPEC-0015：回頭查票與全程紅毯

- 狀態：已實作、技術通過，待真人試玩
- 日期：2026-09-24
- 授權：使用者要求增加意外玩法、設計往回跳自殺行為，並做到死亡累積後只向右走即可通關。

## 行為與驗收

- 據點後 x=790～2500 往左上升跳躍會觸發「回頭查票」；退件章在觸發位置左側 96px 預告 300ms，再下落 220ms、停留 300ms。位置鎖定、每生命一次，可掉頭避開；正常前進及起點彩蛋不觸發。
- 新死因 backtrack-audit 與左側出界 backtrack-exit 歸入 backtrack 區段。後退掉入據點之前的坑也計入 backtrack-exit；使用專屬遞進反應，第 5 次該區段死亡撤除退件章。
- 本關死亡累積 21 次（不限區段／原因）啟用最終援助；舊存檔三段最高援助齊備也啟用。依既有存檔可推導，保存格式不變，不重設死亡。
- 最終援助確實退休敵人／陷阱、停用舊高台碰撞，沿全關鋪設同高紅毯實體道路並限制左側出界；只按右、不注入跳躍、不傳送終點、不偽造結算即可通關。重載／重玩仍保留；全新旅程才清除。
- 紅毯啟用時與恢復遊玩時明確告知「只要向右走」，原 checkpoint 保留。若玩家落在道路以下，以原 checkpoint 救回，避免失控穿出世界。
- 低死亡玩家仍保有已知零死解法；前輪已被援助撤除的小怪不復活。
- 桌面與觸控同為原本左右／跳躍；新增玩法不新增按鍵、依賴或正式美術。

## 驗證

純狀態驗證反向觸發、時間邊界、掃掠碰撞、退休、各死因累積 20→21、舊援助存檔、重載／重玩。Phaser 驗證從新局持續往右死亡至紅毯並通關、往回跳死因、反覆左側出界至紅毯、最高援助不跳整關、checkpoint 保存重載、原零死與彩蛋回歸。截圖檢視退件章及桌面／375×667／橫向紅毯。執行 check、diff --check，更新文件紀錄。真人初見與實體觸控仍需驗收。

## 非目標

不加入戰鬥、隨機必死、難度選單、存檔版本遷移，不自行 commit／push／部署。
