# SPEC-0012：幾何史萊姆小怪原型

- 日期：2026-09-20
- 狀態：已實作、技術驗證通過，待真人試玩
- 授權來源：使用者要求繼續增加惡意、加入史萊姆等小怪，初期用方塊／圓形提示物代替，不過度設計。

## 目標與非目標

用兩種可讀的簡單小怪行為，增加「以為能直接走／跳過，卻被反制」的誤判。只做方塊、圓形、眼睛、簡短提示與蓄力動作；這是使用者本輪明確核准的佔位呈現，不是正式美術。沒有攻擊鍵、血量、掉落、尋路、隨機 AI 或新保存版本。

## 玩家流程與規則

1. 起點平地放一隻方塊突進史萊姆。玩家靠近才短暫蓄力向左衝；直接走會撞上，提早跳過或先引出後撤可避開。每生命只衝一次，衝完攤平休息，不堵住返程。
2. 第一坑後平地放一隻圓形跟跳史萊姆。它平時擋路；玩家在附近向上跳時，它也起跳攔截。從遠處原地跳引它出招，等落下攤平後可通過；直接向它跳容易被攔截。每生命只跳一次。
3. 身體接觸致命，不在本輪加入踩怪或戰鬥判定。形狀與碰撞一致；待機／蓄力／攻擊／休息／援助撤除可辨識。
4. 方塊死因屬 first-gap，圓形屬 warning-strip；既有第 3 次援助顯示行為提示，第 5 次援助讓怪物依王命休息、停止傷害，第 7 次包含撤除。最高援助舊保存直接安全。
5. 暫停及死亡不推進機關時間；重生重設位置、武裝及已出招狀態，已取得援助和死因提示保留。出生點不重疊小怪，完成後不能新增死亡。

## 介面與邊界

- 桌面與手機仍只用左右／跳躍，無新增必需按鍵。外觀使用既有色盤，未發現時標示「方塊史萊姆／圓形史萊姆」，援助後可見休息狀態。
- 引怪後站遠可等招結束，不必靠精確幀操作。反覆進出範圍不重複開招；離開／反向走也不能讓援助撤除的小怪復活。
- 不改玩家物理、舊陷阱幾何、checkpoint 與援助門檻。已知解法的測試輸入可以新增引怪動作，但不能更改遊戲去讓錯誤路線假通過。
- 以獨立資料、純狀態、世界碰撞和佔位呈現實作，不以圖形大小推導遊戲規則。不新增依賴或外部資產。

## 驗收與驗證

- 兩隻怪各有確切死因路線；連續 5 次對應死亡後援助完成。全關學習後維持 0 死。
- 狀態測試覆蓋觸發前／後、跟跳條件、位置、每生命一次、重生、暫停、援助撤除與亂序恢復。
- 實際 Phaser 驗證暫停、重載、最高援助 21 死無新增死亡、前後段受影響路線與正式 dist。
- 桌面與固定 375×667 框實際截圖及引怪路線；真人初見、實體鍵盤與真實多指觸控另列待試玩。
- typecheck、受影響測試、build、diff 檢查通過，更新 STATUS 與本輪紀錄。

## 實作結果

方塊位於 x300，玩家接近後蓄力 180ms、向左衝 120px；圓形位於 x930，對附近上升跳躍反應，蓄力 60ms 後原地跳高 108px、800ms 落回。兩者攻擊完成後攤平無傷害，援助撤除則顯示「奉命休息」。方塊使用矩形碰撞，圓形使用同半徑圓形碰撞；標籤與眼睛僅為呈現，不產生額外碰撞。

20 檔 91 tests、型別及 build 通過。兩隻小怪各精確造成 5 次對應死亡後援助通關，正常及反向路線均 0 死。375×667 暫停、援助重載、零死及最高援助通過；真人初見與真實觸控尚待驗收。
