# SPEC-0023：虛晃落腳地板

- 狀態：已實作、技術通過，待真人試玩
- 日期：2026-10-02
- 授權來源：使用者本日要求「往前跳到前面地板時突然移動，然後慢慢移回來，有虛晃一招的感覺」。
- 接續：SPEC-0010、SPEC-0015；本次只增加古橋前高台的閃躲，不改物理、輸入及保存格式。

## 問題與目標

看似固定的落點，在玩家承諾向前跳躍後閃開，再若無其事回到原位。招式固定、可以學會，不能靠隨機性或持續閃躲封死通路。

## 玩家流程與規則

1. 古橋前 `raised-step` 保持原來尺寸、高度與地表外觀。
2. 玩家向右空中接近高台左緣 96px、腳底在平台頂面上方 130px 內時觸發；步行、倒退、從平台上跳離及平台下方經過不觸發。
3. 高台於 120ms 內向右滑 96px，停留 240ms，再花 1,100ms 緩慢回位；地表及實體碰撞同步移動。時間只計有效遊玩時間。
4. 每生命一次；在岸邊引出後停住，等它回來，再跳上高台並立即補跳，可零死通過。原落腳 180ms 後崩落維持。
5. 因閃躲落空有專屬死因、提示，歸入既有 `intern-bridge`；第 3 次後段援助固定高台，同時撤除閃躲與崩落，第 5／7 次及最高援助也維持撤除。沒有第四條援助階梯。
6. 重生重設位置／動作，援助不復活；重載依原援助恢復。暫停、死亡與進後台不推進動作。全程紅毯停用原平台並停止新機關。

## 介面、資產與非目標

- 桌面與觸控沿用左右／跳躍，沒有額外按鍵。實際觸控手感待真人驗收。
- 移動後露出克制的像素滑軌，回位後保留細微線索；援助後加固定木栓，不能遮住腳底或碰撞頂面。
- 沿用既有地表及色盤，新增原創程式圖形，沒有外部素材／依賴／音效。
- 不追加其他地板、不改第一坑、後台、結局、援助門檻，不自行提交或發布。

## 驗收與驗證

- 純狀態：正常與反向／地面／高度邊界觸發、快退慢回時間邊界、每命一次、重生、援助中途取消、最大援助任意順序。
- 實際 Phaser：直衝落空專屬死因、連續 3 死後固定、固定援助保存重載、空中暫停位置不動、已知零死解法、21 死紅毯。
- 實際畫面：桌面、375×667、667×375，落點／觸控可達。瀏覽器測試使用獨立進度。
