# SPEC-0013：終點判定、連續蓋章與遊玩介面

- 狀態：已實作，技術驗證通過，待真人試玩
- 建立／更新：2026-09-23
- 授權：使用者本日要求「繼續推進專案、增加難度、優化 UIUX」，並回報最後落下攻擊碰到未死亡。
- 關聯：SPEC-0011、SPEC-0012、SPEC-0005、game-shell 視覺基準。

## 問題與目標

終點印章目前只在動畫完成時檢查玩家中心點；下落途中及邊緣接觸可能漏判。改為與可見矩形一致的連續碰撞，低幀率仍不可穿透。增加可預判的第二次蓋章，保留世界因死亡而援助的核心。

## 規則與玩家流程

- 首次進入終點前觸發區，印章預告落點，落下、短暫停留，再於右側落點補蓋一次。
- 活躍印章碰到角色碰撞矩形即死亡；預告線、收回與奉命停用外觀不致死。外觀與碰撞共用尺寸及位置。
- 可在觸發後留在最後高台引完兩次攻擊，再跳向終點。
- 印章死因仍是 goal-approval-stamp；第一次中招後印章撤除、終點前移，重載保留，最高援助不重新阻擋。
- 未中印章而死於其他機關時，下次重生重新引招；暫停不推進攻擊。
- 最高橋段援助會直接撤除印章；先前保存的最高援助沿用。兩次落印相隔 1,020ms，各預告 200ms、下落 460ms、停留 220ms，第二次位於第一落點右側 80px。
- 不改角色物理、存檔版本、既有援助門檻，不新增戰鬥、美術資產或輸入鍵。

## 介面與輸入

- 延用深青、羊皮紙、王室金色與既有字體 token；舞台仍為主體。
- 舞台外顯示已抵達的安全據點，死亡／援助／重生文字固定位置，避免文字變長使觸控鍵跳動。
- 手機暫停選單可完整讀取及操作；至少 56px 目標、12px 間距、清楚焦點。
- 選單開啟時遊戲輸入停用，空白鍵可正常啟動原生按鈕；背景失焦／切分頁自動暫停，返回需主動繼續。
- 不新增音效，維持減少動態偏好。

## 驗收與測試

- 複現舊版下落中重疊未死亡；加入空中、邊缘、錯開、跨幀、預告／退場、兩連擊與援助回歸。
- 實際 Phaser 路線：碰撞精確死因、重生／重載後撤除、暫停時間凍結、零死亡整關與最高援助通關。
- 桌面與 375×667、667×375、844×390 介面截圖；檢查焦點、操作尺寸、遮擋與必要狀態。
- typecheck、受影響測試、build；不增加執行依賴或素材下載。
- 真人初見難度與實機多指手感交由使用者試玩，不以自動化宣稱完成。
