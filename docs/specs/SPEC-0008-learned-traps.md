# SPEC-0008：首關反直覺陷阱與可替換呈現

- 狀態：已實作、技術驗證通過，真人初見與觸控手感待試玩
- 建立／更新：2026-09-20
- 依據：使用者指出「不夠惡劣」、提供貓里奧參考，並明確要求暫留美術與台詞、確保可抽換結構、優先玩法。
- 關聯：SPEC-0001、0002、0007。0007 的玩法不變限制只適用上一輪。

2026-09-20 接續：使用者要求第一坑與金幣進一步增加惡意，見 [SPEC-0009](SPEC-0009-coin-and-pit-ambush.md)。下文「第一坑仍可正常跳過」是本規格當時範圍；最新版已增加需先引出的坑底攻擊，並保留學習後零死解法。

## 目標與非目標

讓首關具備「合理操作被反咬 → 看懂規則 → 穩定破解」的段落，死亡仍推動援助。這次實作隱藏頂板與假斷路兩組機關；不改移動速度、跳躍物理、輸入、存檔版本、2／3／5／7 門檻，不擴增關卡、不重畫美術、不潤飾既有台詞。追人寶箱等前次討論維持提案。

## 規則

1. 第一坑仍可正常跳過。第一落點上方有隱藏頂板：太早起跳逃避地面王徽會撞頭、失去高度；稍晚起跳能同時避開頂板與王徽。頂板只阻擋上升撞擊，不攔水平移動或下落。撞擊後顯形，本次嘗試的後續落坑／王徽死亡記為 `hidden-ceiling-bait`，歸入 `first-gap`。一般王徽死亡也歸入第一段援助，避免孤立且永不放水。
2. 第二段看似斷路，實際有與兩岸同高的單向透明地板。走過會顯出承重路面；自然的起跳路線撞上隱藏空中危險帶，記為 `jumped-at-false-gap`，歸入 `warning-strip`。危險帶碰觸後顯形，不靠隨機或不可逆按鍵限制殺人。
3. 第一段累積 3 死：原落點移近並撤除頂板；5 死：原彈簧生效並撤除王徽；7 死：原橋生效。第二段累積 3 死：原危險帶縮短並揭露透明路；5 死：原繞道生效並撤除空中危險帶；7 死：原危險帶退休。沿用既有 effect ID，舊存檔重載取得相同援助。
4. 重生清除「本次曾撞頭」歸因，保留已顯形線索與援助。重載時從死亡原因／既有援助恢復必要線索；沒有死亡的探索顯形不額外寫存檔。場景重啟重新建立機關，所有物件／計時器跟隨 Phaser 場景生命週期。

## 模組與素材替換

- 幾何與解除援助對應在 content；純規則狀態不依賴 Phaser、顏色、文案。
- 機關控制器持有獨立 Zone 碰撞體，呈現由 visuals 建立。替換呈現不得以圖片尺寸改變碰撞尺寸。
- 死因與台詞映射集中為 content 資料，既有文字保留；新增死因沿用既有段落台詞，後續可獨立改寫。
- 鍵盤／觸控使用相同 ActionState，不新增操作。無新外部素材、音效或套件。

## 驗收與邊界

- 不熟悉的早跳路線實際撞頂板並死亡；稍晚跳的已知解法可零死通關。
- 假斷路直接走可以通過；起跳會遭空中伏擊；不誤殺沿地面行走的玩家。
- 同一次事故只能記一次死亡；重生不沿用上一輪撞頭歸因；停止／暫停不推進物理計時。
- 連續失敗會取得第 3／5 次援助，援助後同一操作可通過；最高援助整關維持預置 21 死、不增加死亡。
- 保存重載、零援助、最高援助、反向彩蛋、正式產物路線通過。手機尺寸驗證實際引擎路線；真人觸控手感另列未驗證。

## 驗證方法

純狀態測試驗證歸因／重設／效果順序與冪等；幾何檢查驗證步行頭部安全距離及透明支撐覆蓋；瀏覽器 fixture 用真實 ActionState 與 Phaser 碰撞驗證陷阱、重生、援助、已知解法，不瞬移玩家或注入私有遊戲狀態。執行 `npm.cmd run check` 與針對性瀏覽器回歸，結果寫入 logs／STATUS。
