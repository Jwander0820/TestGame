# SPEC-0010：後半段連環陷阱

- 日期：2026-09-20

- 來源：使用者確認前面概念 OK，要求後面追加惡意與優化。

- 證據：[本輪實作與驗證紀錄](../logs/2026-09-20-rear-gauntlet.md)。

## 目標與機關

在通過假斷路後增加連環誤導，維持可學習、可重現的零死路線。

1. 高台（raised-step）：落腳後 180ms 崩落。停留／直接走會掉下去，落地後再跳可越過。
2. 橋前迎面飛行物：接近橋頭發射一次低空橫掃。剛躲過高台後繼續跑會中招，可跳過或先引出。
3. 橋尾地刺：通過橋後才從下一個落點冒出；提早跳可越過地刺及下一個坑。橋後 checkpoint 出生點向左移到同一安全平台 x2250，避免重生直接進入攻擊區。
4. 終點上方伏擊：在終點前急著起跳，會撞到隱藏致命夾板；更靠近平台末端再跳可避開。
5. 終點落點地刺：剛避開王令後，落地路線還有地刺。晚跳可以同時跨過上方機關、王令與地刺；既有終點搬近的公開援助仍可縮短這一段。

## 援助、死亡、重設

- 新死因歸入後半段既有 intern-bridge 阻塞段，不加保存版本或第四條援助階梯。
- 第 3 次：原橋加固，同時固定高台並揭露橋尾／終點危險提示。
- 第 5 次：原安全網，同時撤除橫掃與終點上方機關。
- 第 7 次：原永久橋，同時撤除橋尾與終點地刺。最高援助 21 死舊保存仍安全。
- 延遲與飛行使用有效遊玩時間；暫停與死亡不推進。重生清除已啟動機關／飛行物，恢復高台，保留援助及已顯形線索。重新整理從死因與援助恢復必要狀態。
- 跨 checkpoint 的後段事故沿用現行 director 的累計／連續事故規則；實際回歸需證明第 3／5／7 次援助可取得。
- 圖形、碰撞、幾何、台詞分離。前面陷阱、角色物理、鍵盤／觸控介面不改。

## 驗收

- 五種新死因各有實際引擎故意犯錯路線；學會後整關 0 死。
- 過早起跳路線先累積 5 次上方伏擊死亡，再因同一跳法落入地刺 2 次，總計 7 次後完成；驗證兩層援助確實各解除一層攻擊。
- 逐段犯錯後能取得援助完成，沒有卡在無援助的死因或危險出生點。
- 最高援助維持預置 21 死；保存重載、前半段惡意、終點搬近、正式 dist 流程仍通過。
- 375×667 路線與暫停／重生測試；真人初見與多指觸控另列待驗收。
