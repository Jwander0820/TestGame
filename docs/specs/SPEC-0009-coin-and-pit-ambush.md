# SPEC-0009：金幣誘餌與第一坑連環伏擊

- 狀態：已實作、技術驗證通過；待真人初見與觸控試玩
- 日期：2026-09-20
- 依據：使用者明確要求金幣具惡意、第一坑加入空氣磚及向上飛的殺傷物，整體更惡意以支撐援助吐槽。
- 接續：SPEC-0008；美術／台詞仍以可替換暫留為原則。

## 目標與流程

第一坑在原本可跳過的幾何上增加可學習的連環陷阱，不只縮短操作時間。玩家接近坑邊即觸發坑底往上竄的殺傷物；立即跳會在空中遇上。先在岸上引出、等它離開再起跳可過。坑內另外放置真正有碰撞的隱藏磚，截斷晚跳／追誘餌的軌跡，碰撞後顯形。

左側原有 8 枚金幣及第一坑空中的新金幣都是誘餌。接觸後外觀短暫轉紅，延遲後變成致命帶刺物；停留會死，持續撤離有可重現解法。這不是金幣加分系統，也不以永久鎖操作懲罰玩家。

## 規則與重設

- 空氣磚只擋上升撞頭，不做看不見的水平牆；第一坑的撞磚落坑記 `first-pit-air-brick`。
- 坑底攻擊每次嘗試最多自動發射一次，使用固定位置／速度，死亡記 `first-pit-riser`。角色停留岸上可等它飛走；重生才重新上膛。
- 金幣接觸後 300ms 變成短暫殺傷區，死因 `bait-coin-burst`。單枚每次嘗試觸發一次，不在角色死亡時繼續留下下一輪傷害。重生重新待命，是否已發現危險可由已有死因恢復。300ms 保留持續移動逃出 48px 傷害區的餘裕，避免普通經過也必死。
- 以上新死因均歸入 `first-gap`。3 次失敗：沿用落點移近，撤除新舊頂板、揭露誘餌；5 次：沿用彈簧並停用坑底攻擊、金幣傷害和落點王徽；7 次：原橋完成。
- 沿用既有 effect ID、存檔版本與輸入；舊援助保存重載時同樣停用新機關。
- 規則、幾何、圖形、死因文案分檔；不重做整體美術，不重寫原有台詞。新死因只加短暫用語，方便後續換稿。

## 邊界與介面

- 鍵盤／觸控沿用左右與跳躍，不加特殊按鍵。
- 場景暫停時延遲與飛行都停止；重生清除飛行物及已武裝金幣，防止跨生命殺人。
- 已援助的機關不能在延遲回呼後復活；同次事故只記一次死亡。
- 主線與反向探索保留零死解法；貪拿金幣及直覺跳坑各有故意犯錯的瀏覽器路線。

## 驗收

1. 真實 Phaser 路線驗證直接跳坑會被向上攻擊殺死；學習後等待再跳可零死通關。
2. 引出攻擊後晚跳能實際撞到坑內空氣磚，後續落坑歸因正確。
3. 既有金幣接觸→武裝→傷害，故意停留至少產生一次金幣死因；逃離可生還。
4. 連續死亡得到 3／5 次援助並能通過；最高援助維持預置 21 死、不新增死亡。
5. 重生、保存重載、正式建置路線及手機尺寸新陷阱路線通過。真人初見與多指觸控仍待試玩。

## 驗證方法

純狀態測試覆蓋武裝延遲、一次觸發、重設、援助撤除；瀏覽器測試使用真正輸入與物理，分辨「撞磚」「向上攻擊」「金幣」死因，不用瞬移或把測試成功條件放寬成任意死亡數。執行 check 與相關回歸，證據記在 logs／STATUS。
