## 問題與價值

首關已完整驗證惡作劇、死亡學習與世界作弊援助。第二關將舞台移入王城鐘塔工坊，以運送、蒸汽與分揀機關提供新節奏，而非複製森林地形。死亡仍推進內容，零援助仍有確定解法。

## 目標與非目標

- 完整第二關起點、三段主要機關、安全據點、結算與正式入口接續。
- 新增搭乘會斜向升高的運送載台、先預告再噴發的蒸汽閘門、逆向輸送帶與貨物分揀壓機；終段以鐘塔階梯及終點大鐘收尾。
- 以原創程式像素美術畫出石砌拱窗、銅色齒輪、管線、鏈條與鐘塔，沿用主角及既有色盤。美術與趣味仍待使用者驗收。
- 不含 Boss、戰鬥、新按鍵、遠端保存、部署、提交、推送或第三關；不改第一關物理、存檔版本與既有援助。

## 玩家流程

1. 第一關完成面板選「前往第二關」；已有第一關完成存檔者可從標題繼續第二關。
2. 踩上運送台，站定搭乘到較高對岸；可跳離，但衝過坑洞會落空。
3. 蒸汽閘門以壓力表與警示先預告，等它洩壓後通過。貨物壓機先亮出落點，玩家可退到安全處等一次完整動作。
4. 輸送帶向左搬運站在其上的玩家；跳躍暫離輸送帶，持續向右仍能推進。
5. 段落據點保留，攀上鐘塔敲響通行鐘完成。可探索非必要旁支取得一筆特殊事件。
6. 同段落第 2 死吐槽、第 3 死增加預告或橋板、第 5 死公開加橋／關閥／停帶、第 7 死永久撤除該段阻礙。本關獨立累積 21 死後工務處鋪設連續同高通道，所有機關退休，只向右不跳即可完成。

## 規則與保存

- 新資料使用 `level-two`，維持 v2 `levels` 任意 key 保存；第一關的死亡不直接解鎖第二關援助。
- 內容、純機關狀態、Session 交易、Phaser 世界效果、美術各自分離。
- 載台幾何：起點中心 (484,430)、終點 (670,382)、寬 144；先等候 700ms，再以 1500ms 搬運，抵達後保留，不以隨機決定行程。
- 地面頂面：入口 430、載台對岸 382、蒸汽段及輸送段 430、終段階梯 430→382→350。最終援助頂面統一 430，停用會妨礙行走的舊高台。
- 蒸汽落點 x=1060，預告 800ms、噴發 1100ms；壓機落點 x=1860，預告 900ms、落下 250ms、停留 200ms、回收 600ms。每命一次；援助可延長預告，退休立即取消預備攻擊。
- 任何死亡最多計數一次。重生清空輸入、重設本命機關，已保存援助保持；重玩重設據點但保留累積死亡／援助。
- 暫停、失焦、死亡及完成不推進機關有效時間，完成後不再判定危險。沒有存檔或存檔無法解析時安全啟動。

## 桌面與觸控

- 沿用左右／跳躍三種抽象輸入與物理，沒有額外互動鍵；搭乘與敲鐘以站位觸發。
- 正式外框接續按鈕用原生 button、可見焦點，暫停／重玩／標題均作用於當前關卡。
- 據點文字及完成面板反映第二關；全旅程死亡徽記與本關援助計數分開。
- 960×540 舞台，直向保持比例、控制列置於下方。減少動態時停用裝飾齒輪轉動與震動，保留必要玩法運動。文字回饋不依賴音訊。

## 驗收條件與方法

- AC-1：正常第一關完成後可開第二關；舊第一關存檔可接續；預設 `createGame` 仍啟動第一關以保留舊測試。
- AC-2：實際 Phaser 已知路線零死完成新關；載台正確承載玩家，蒸汽與壓機可等待破解。
- AC-3：各機關連續死亡援助及本關 21 死後只向右通關；援助不跨關汙染，重生／重載不會卡死。
- AC-4：空中與預告中暫停後機關位置／時間不變，恢復後接續；保存據點和完成狀態。
- AC-5：桌面、375×667、667×375 正式外框實際截圖檢查角色、落點、危險、字幕與觸控可達。
- 單元測試覆蓋狀態時間、退休、幾何與 Session 保存交易；瀏覽器提供獨立記憶體試玩與可重現路線。執行 `npm.cmd run check`、`git diff --check` 及第一關零死／21 死回歸。
