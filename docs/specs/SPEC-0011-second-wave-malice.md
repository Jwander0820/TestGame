## 問題與目標

現有陷阱多在迎面或落點發動。本輪增加「已躲過，卻還沒結束」與「安全高台不能久留」兩種誤判；保留可學習的零死路線及死亡後世界主動幫忙的核心。

## 玩家流程與規則

1. 橋前橫掃發射後，延遲從左側折返追擊；第一次跳過迎面攻擊後，玩家需在橋上再跳一次。每次生命只發動一輪，固定時間與速度。
2. 跨過橋尾抵達最後高台時觸發上方重槌。繼續前進可離開打擊範圍；停在落點喘息會遭延遲打擊。落下前顯示危險輪廓，死後保留已發現提示。
3. 兩種死因均歸入 intern-bridge。第 3 次援助揭露提示；第 5 次安全網援助撤除兩招，第 7 次永久橋亦包含撤除。舊最高援助保存不可新增死亡。
4. 使用有效遊玩時間，暫停及死亡不推進。重生清除武裝與移動狀態，援助不復活；重載由既有死因與 effect 還原。存檔版本、checkpoint、移動／跳躍物理及 2／3／5／7 門檻不變。

## 非目標與介面

不重做美術、台詞與關卡整體結構，不加新操作或隨機必死機關。桌面鍵盤、手機左右／跳躍沿用同一動作；新增圖形使用既有色盤與獨立碰撞 Zone。新死因僅加可替換的繁體中文短句，不新增外部資產、依賴或音訊。

## 邊界與驗收

- 兩招各有實際引擎故意犯錯路線，精確驗證各自死因 5 次並在援助後完成；已知整關解法 0 死。
- 武裝延遲前／後、移動座標、一次觸發、暫停、重生、已武裝時撤除與亂序援助還原均有測試。
- 重生點不能直接位於傷害區；完成後不能再計死亡；反向探索不產生無解封鎖。
- 舊五種後段死因與前半段、終點搬近、最高援助及保存重載回歸。
- 桌面與 375×667 實際引擎路線及截圖；真實手機多指操作另列待試玩。
- 執行單元測試、typecheck、build、git diff --check，更新 STATUS 與本輪紀錄。

## 技術依據

沿用資料／狀態／世界／呈現分離，擴充既有移動機關以支援垂直落下與武裝提示。移動靜態 Zone 需同步 body，依 [Phaser Arcade Physics 官方文件](https://docs.phaser.io/phaser/concepts/physics/arcade)。Modern Web Guidance 已搜尋與查看目錄，未找到對應遊戲碰撞指南，不引入無關網頁動畫方案。

## 實作與驗收結果

回頭追擊於橋前觸發後 900ms 從 x1620 向右移動，重槌於最後高台入口觸發後 400ms 落下。每生命各一次，兩者於第 5 次後段援助撤除；橋上補跳及高台不停留可零死完成。新增兩個傷害 Zone 及兩個觸發 Zone，沒有外部資產或依賴；沿用既有色盤的程式圖形為暫用呈現。

19 檔 84 項測試、型別、build 通過。桌面及固定 375×667 iframe 的整關 0 死、兩種新增死因、暫停、援助重載及最高援助均有本輪證據；真人初見及真實多點觸控未驗收。
