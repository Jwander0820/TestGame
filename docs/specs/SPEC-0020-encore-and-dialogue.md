## 目標與玩家流程

終點前的休息高台新增第二把重槌：第一槌落在 x2540，第二槌延後落在 x2660。急著離開第一槌又在門前等候，會遭補點名；停在兩槌之間、等落槌結束再前進可零死通過。兩槌碰撞區之間留 64px，扣除角色寬度仍有 36px 站位範圍。落點固定並預告，每生命一次，不追蹤玩家。

關卡負責嘴硬、工務處負責拆台、勇者偶爾回嘴。開場、沿途、據點、死亡、援助、閒置與結局有連貫語氣；同死因重複死亡提供具體操作提示。援助先交代實際改變，再接笑話。

## 規則與邊界

- 補點名於 x2490 觸發，延遲 1100ms，自 y160 以 600px/s 下落，持續 600ms；尺寸 56×40，歸入 intern-bridge。第 3 次援助揭露、第 5／7 次撤除；最高援助保存與紅毯不得復活機關。
- 暫停／死亡期間陷阱不推進，重生重設每生命狀態，援助與發現由原存檔推導。不改物理、保存版本、據點或 2／3／5／7、21 死門檻。
- 對話每句至少保留 3.2 秒；低優先序路過台詞不能覆蓋死亡／援助。新死亡、紅毯與結局可取代舊對話；重生不立即清除死因台詞。暫停凍結對話，不強迫玩家等待或按確認。
- 讀檔不補播身後的沿途事件；對話不寫入存檔、不影響援助交易。
