# 2026-07-15 Phaser 技術尖峰完成紀錄

## 結果摘要

Vite + TypeScript + Phaser 4.2.1 能滿足目前的純靜態瀏覽器遊戲骨架需求。已完成固定 16:9 平台場景、鍵盤／觸控共同輸入、死亡去重、快速重生、版本化本機保存、手機旋轉提示與原地等待彩蛋。

技術尖峰骨架可保留並演進為正式垂直切片，不需更換引擎或引入後端。

## 實作內容

- Vite 8.1.4 + TypeScript 7.0.2 + Phaser 4.2.1。
- Phaser Arcade Physics 固定 60 Hz、960×540 邏輯畫面與 `FIT` 縮放。
- 程式繪製的角色、平台、危險區與紙張批改風格佔位圖。
- 鍵盤方向鍵／A／D／W／空白鍵和 DOM 觸控按鈕共用 `ActionState`。
- 多指來源分開追蹤；任一來源仍按住時不會錯誤釋放動作。
- `ProgressStore` 驗證版本與死亡數，讀寫儲存被封鎖時仍安全啟動。
- `IdleTrigger` 只計算連續有效等待時間，首次 8 秒觸發一次吐槽。
- 手機直向顯示旋轉提示；小型橫向畫面預留底部／左右觸控安全區。
- `base: './'` 使建置資產使用相對路徑，可部署至網站子目錄。

## 建置證據

- `dist/index.html`：2.52 kB。
- `dist/assets/*.css`：4.59 kB，gzip 1.71 kB。
- `dist/assets/*.js`：1,385.80 kB，gzip 361.82 kB。
- `index.html` 中 JavaScript 與 CSS 均使用 `./assets/...` 相對路徑。
- 建置輸出沒有 sourcemap，避免額外部署約 11 MB 開發資料。

Vite 仍提示未壓縮 JavaScript chunk 超過預設 500 kB。主因是 Phaser 執行期；gzip 後約 362 kB，低於垂直切片暫定 5 MB 努力目標，因此本階段記錄但不為消除提示而拆分唯一遊戲入口。

## UI／UX 清單

- DOM 按鈕使用語意化 `button`、可讀 aria-label 與可見 `focus-visible`。
- 跳躍圖示使用 SVG；沒有以 emoji 作結構圖示。
- 觸控鍵至少 60×60 px、間距 12 px，符合最低 44×44／8 px。
- 按壓使用 160 ms 位移與陰影回饋，未改變版面占位。
- `viewport-fit=cover` 與 `env(safe-area-inset-*)` 已納入固定區域。
- 危險區同時具有顏色、黑色外框及文字，不只依靠紅色。
- 已實作 `prefers-reduced-motion: reduce`。
- 沒有遠端字型、圖片或第三方腳本，因此目前沒有字型阻塞、圖片位移與第三方載入風險。
