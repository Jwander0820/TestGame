# 2026-09-28：回頭探索與工務處施工後台

- 規格：[SPEC-0021](../specs/SPEC-0021-backstage-maintenance-room.md)
- 狀態：本機實作與技術驗證完成；視覺、趣味、實體觸控待使用者驗收。未 stage、commit、push 或部署。

## 實作

左上層平台落地後向左起跳可進入獨立施工房。工務員趕工、關卡施工單、尖刺驗收與偷懶史萊姆提供靠近觸發的對話。施工牌有 650ms 警告，被砸中由安全網送回房內入口，不增加死亡。右側出口隨時可用，回到主線下層平台。房內採既有色盤的原創程式美術試作，[來源與狀態](../art-outsourcing/10-backstage-prototype.md)另記。

主線 Scene 睡眠，物理與陷阱時間暫停，返回後繼續。獨立發現 ID 存入既有陣列，房內不寫主線死亡、援助、據點或完成狀態。轉場清除鍵盤與觸控持有狀態；正式外框的暫停、重玩與後台進度標示同步接入。對話沿用至少 3.2 秒閱讀時間，快速探索只保留最新待播互動。

## 測試中修正

144Hz 渲染可在下一個物理步進前仍回報落地；入口狀態不能立即清掉剛起跳資格。已保留至真正離地或落回平台，並加入回歸測試。

原重訪測試離開後立即再跳，會撞到主線原已武裝、房內凍結的金幣。返回落點本身安全；測試改為等 800ms 再跳，不修改或吞掉原機關。完成兩次拜訪仍為零死。落牌命中驗證另限定在房內觀察復位，避免把出口轉場當作命中成功。

工務員與房內物件是試作，台詞趣味與美感仍由使用者確認。桌面尺寸模擬不等同實體手機；真實多指觸控、OS 失焦切換及個人手感仍待驗。失焦沿用既有暫停事件並已將場景選擇切至實際活動房間，未冒稱完成真人測試。
