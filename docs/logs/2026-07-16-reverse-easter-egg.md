# 2026-07-16：完成起點反向探索彩蛋

## 規格來源

SPEC-0001 Beat 1 要求玩家若反常地往起點左側探索，可以進入不阻塞主流程的彩蛋區，找到一批沒有實際用途的金幣與對應吐槽。

## 設計與實作

- 在起點左側頁邊加入兩層紅框「批改膠帶」平台，使用只允許由上方落地的碰撞方向；玩家可從下方穿越，不會被平台底面卡住。
- 玩家需往左並分兩次跳躍登上彩蛋區；平台高度與水平區間納入純資料關卡配置。
- 放置 8 枚黃色金幣，每枚正面直接標示紅色 `0`，作為本彩蛋唯一的視覺記憶點；不另加通用寶箱或發光特效。
- 首次進入觸發區時顯示「恭喜找到 8 枚完全沒有用途的金幣」，並記錄 `reverse-zero-coins`。
- 重新整理或重玩後不重播完整吐槽；金幣改以較低透明度顯示，標籤改為「已領取 · 仍然沒用」。
- 彩蛋平台與主路線分離；完全不探索左側不會改變 checkpoint、死亡門檻、援助或終點路線。

## 驗證結果

- 新增秘密平台路線幾何測試：兩次必要跳躍均保留至少 12px 垂直與 20px 水平理論餘裕。
- `npm test`：5 個測試檔、23 項測試全數通過。
- `npm run build`：TypeScript 與 Vite 正式建置通過。
- 桌面與 375×667 手機畫面確認：彩蛋入口位於左側頁邊，沒有遮住右側主路線、操作提示或觸控鍵。
- 瀏覽器 console：無 error／warning。
