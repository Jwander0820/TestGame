# 2026-07-16：第一關進度工作階段重構

## 背景

`VerticalSliceScene` 同時處理 Phaser 場景呈現、物理、輸入、死亡事件組裝、進度讀寫、彩蛋保存與援助統計。存檔規則散落在多個場景方法中，使未來增加關卡或修改保存格式時容易漏改，也難以在不啟動瀏覽器的情況下直接驗證。

## 本輪範圍

- 建立 `LevelOneSession`，集中第一關的起始位置判定、進度標記、死亡紀錄、彩蛋保存、援助查詢與完關轉換。
- 場景保留輸入、物理、視覺及演出責任，透過工作階段介面存取進度。
- 為工作階段補上單元測試，涵蓋存檔重生點、2／3 次死亡反應、一次性彩蛋及完關狀態。
- 不改動關卡座標、移動參數、援助門檻、使用者文案或既有保存格式。

## 驗證策略

本項屬於不改變產品行為的內部重構。依風險分層守則執行型別檢查、完整單元測試與正式建置，不重複進行人工瀏覽器操作。實際結果於完成後補記。

## 實際結果

- `npm run typecheck`：通過。
- `npm test`：9 個測試檔、34 項測試全部通過。
- `npm run build`：正式靜態產物建置通過。
- Vite 仍提示 Phaser 主 bundle 超過預設 500 kB；gzip 約 367 kB，與重構前同級，本輪沒有新增正式相依套件。
- 依分層驗證策略未重跑人工瀏覽器操作；既有整關瀏覽器證據保留，後續里程碑再集中驗收。
