# 2026-07-17：第一關惡意設計深化

- 狀態：程式第二階段完成，等待真人試玩
- 關聯：SPEC-0001、SPEC-0002、`docs/discovery/open-questions.md`
- 參考方向：使用者指定《超級貓里奧》與《變態人生大冒險》的預期反轉及死亡學習節奏；不複製其關卡、角色、美術或文案

## 背景

既有 2200×540 垂直切片只有第一坑與警告區兩個主要阻礙，通過第二段後大多只需向右走到旗幟。畫面及行為能驗證系統，但缺少「先建立合理預期，再在玩家最自然的動作上反咬」的惡意平台遊戲節奏。

完整世界的 3+1、4+1 或原始 5+1 仍未定案；本階段只深化第一關，不擴張其他關卡。

## 規格與內容變更

- 將第一關延長至 3000×540，形成第一坑、認證步道、模範安全橋與終點審核四段節奏。
- 新增落腳伏擊：玩家第一次落上安全平台後，「補考章」從平台升起；觸發後保持可見，熟悉玩家可跳過。
- 將警告區初始外觀改為一般綠色王城認證步道，第一次死亡後才揭露紅色危險狀態與「認證撤回」。
- 模範橋初始沿用普通平台外觀，踏上後才顯示臨時修補材質並開始塌落。
- 新增模範橋 2／3／5／7 次死亡反應：行政卸責、延長塌落時間、下層安全網、永久禁止倒塌。
- 新增終點前一次性審核章：利用玩家看見旗幟後自然加速的預期；觸發後留在場上且不再次偷襲。
- 新增分區路線吐槽、重複死因輪替文案，以及依零死亡／無援助／有援助改變的結算文案。
- 以程式圖形建立森林丘陵、樹木、雲層與遠方王城，移除原本覆蓋整關的測試方格背景。

## 援助疊加修正

真實瀏覽器最高援助整關揭露兩個既有疊加問題：

1. 第 3 階彈簧與第 4 階膠帶橋同時存在時，彈簧會把玩家強制彈向新的落腳伏擊。
2. 停用彈簧後，膠帶橋與被移近的平台有 22px 高差，形成最高援助路線的垂直牆。

修正後，第 4 階膠帶橋會停用彈簧碰撞，並把第一落腳平台降至橋面同高；最高援助因此成為真正連續的保證路線。

## 第二階段：王城驗收視覺敘事

- 依實際瀏覽器截圖收斂出「王城公文遊樂場」方向：墨色粗框、王城綠、警告紅、文件黃與紙張白。
- 新增新手草坡、認證施工區與王城驗收區三段背景，加入施工樁、紅色更正線及區域公文標記，降低測試矩形與大面積留白感。
- 將角色與平台暫代材質改為同一套公文／驗收視覺語言；本階段仍只使用程式圖形，不引入來源不明素材。
- 新增固定的「王城驗收檔案」，直接由三個 blocker 死亡資料顯示待驗、事故或強制合格狀態；沒有建立第二份進度。
- 終點審核章造成死亡後，重生時會把旗幟與實際完成區向左搬近 120px；結算加入旗幟降下、公文碎紙與「免驗錄取」蓋章。
- 844×390 檢查發現外層暫停按鈕會壓住原右上角檔案，調整至中右安全區後不再與上方票券或底部觸控鍵重疊。

## 第二輪瀏覽器問題與修正

專用終點事故路線第一次執行時以 0 死完成，證明審核章雖有動畫卻沒有穩定命中。原因是 70px 觸發區在玩家碰撞盒碰到左緣便開始 460ms 倒數，既有測試卻錯用觸發中心計算落點。將觸發區縮為 18px，並把測試公式改成「觸發區左緣減玩家半寬」後，實際瀏覽器結果為：

- `status=completed`
- `deaths=1`
- `goalDeaths=1`
- `sawRelocation=true`
