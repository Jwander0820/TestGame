# 2026-07-16：手機直向備援核准

## 使用者決策

- 手機仍以橫向遊玩為主要體驗。
- 玩家若保持直向且不旋轉裝置，不得被旋轉提示阻擋。
- 直向時把左、右、跳躍按鈕排列在遊戲舞台下方。
- 實際遊戲舞台維持原本 16:9 等比例，避免 Canvas、素材與碰撞配置因方向改變而變形。

## 實作影響

- 移除直向模式隱藏 Canvas 與控制列的規則。
- 直向頁面依序顯示標題／死亡數、16:9 舞台、狀態文字與觸控控制列。
- Phaser 仍固定使用 960×540 世界視窗與相同物理參數，只由 CSS 等比例縮放外觀。
- 橫向低高度裝置維持控制列疊於安全區外側的配置。

## 驗收補充

- 需驗證至少一個窄手機直向尺寸，確認舞台未拉伸、控制鍵可見、頁面無水平捲動。
- 真實觸控裝置仍需驗證同時按住方向與跳躍。
