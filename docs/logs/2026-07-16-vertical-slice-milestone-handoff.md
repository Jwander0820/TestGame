## 已核准與已實作

- SPEC-0001：單關 3–5 分鐘垂直切片，左／右／跳躍三鍵，桌面鍵盤及手機觸控。
- 橫向為主要手機體驗；直向維持 16:9 遊戲舞台，三個觸控鍵放在下方。
- SPEC-0002：同一阻礙第 2／3／5／7 次死亡依序吐槽、小幅介入、公開援助與保證繞過。
- 第一坑依序提供吐槽、移動平台、彈簧與膠帶橋。
- 危險帶依序提供吐槽、縮短、上方繞道與「已下班」。
- 標題、繼續、暫停、重玩、結算、靜音、清除紀錄二次確認及本機保存。
- 原地安全站立約 8 秒的一次性等待彩蛋；背景與失焦時間不計入。
- 起點反向兩層秘密平台、8 枚零價值金幣及一次性吐槽。
- 純資料導演、第一關進度交易、世界效果與場景生命週期已拆成獨立可測試邊界。
- 援助效果只有成功建立後才寫入 active effect；失敗或例外不保存半套用狀態並可重試。

```powershell
.\play-local.cmd
```

開啟啟動器印出的 Local URL，通常是 `http://localhost:5173/`。詳細操作、試玩重點與回報格式見 `docs/testing/local-playtest.md`。
