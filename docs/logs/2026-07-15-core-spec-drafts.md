# 2026-07-15 核心規格起草紀錄

## 目的

在產品與技術提案等待確認期間，先將首個垂直切片及核心同情／作弊機制轉成可審閱的行為規格，不進入產品實作。

## 產出

- `SPEC-0001-vertical-slice.md`：定義短關卡流程、輸入、死亡重生、觸控、保存、靜態部署及驗收條件。
- `SPEC-0002-sympathy-director.md`：定義死亡事件、阻礙、反應層級、援助選擇、保存資料與故意送死行為。
- `docs/specs/README.md`：建立規格狀態索引。

## 本輪設計判斷

- 垂直切片使用局部死亡門檻來防止玩家卡在單一阻礙；原始概念中的 10／20／30／50／80／100 次保留為全域喜劇里程碑。兩者不互相取代。
- 關鍵援助採確定性選擇，讓相同狀態能重現相同結果並可靠測試。
- 疑似故意死亡只解鎖吐槽，不會導致難度懲罰。
- 援助的最高層級必須提供保證可通過的路線，但仍以世界內演出包裝。

## 仍待使用者確認

- 單關卡垂直切片、橫向畫面、三鍵操作與 Phaser 技術提案。
- 局部援助門檻是否採 2／3／5／7 次。
- 終點演出、美術方向、全域死亡狀態範圍與事件重播方式。
