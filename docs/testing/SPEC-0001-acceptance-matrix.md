## 已核准範圍中的內容缺口

- 終點已加入審核事故、搬近完成判定、旗幟降下、公文碎紙及驗收檔案蓋章；仍需真人判斷收尾是否好笑而非只確認程式完整。
- 844×390 手機橫向視覺檢查確認驗收檔案不再與暫停／死亡票券或底部三鍵重疊；真實觸控完成流程仍待實機。
- 預期首次完成 3–5 分鐘、10 分鐘內由援助保證通過，尚無真人時間與死亡分布資料。
