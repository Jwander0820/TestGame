# 終點公開放水整關自動試玩

- 狀態：通過
- 最後更新：2026-07-17
- 關聯規格：SPEC-0001 AC-4b、AC-4c

## 目的

驗證終點審核章初見能命中自然奔跑者，但死亡後不再重複偷襲；客服搬動的不只是旗幟圖像，也包含實際完成判定。

## 執行方式

1. 以 `tests/browser/goal-mercy.html` 啟動隔離的記憶體進度。
2. 使用正式 `ActionState` 與 Phaser 物理完成前半關。
3. 第一次進入終點區時刻意不跳，接受審核章伏擊。
4. 重生後在已知時機跳過印章，走入搬近後的完成區。
5. 檢查死亡總數、死因、搬近訊息及完成狀態。

## 2026-07-17 結果

- `status=completed`
- `deaths=1`
- `goalDeaths=1`
- `sawRelocation=true`
- 結算文案為「搬終點不列入協助申報」，與公開放水演出一致。

瀏覽器驗證曾揭露原 70px 寬觸發區會在玩家進入左緣時過早啟動，印章落地時自然跑速玩家仍差數個像素才進入致命範圍。修正後觸發寬度為 18px，幾何測試也改以玩家碰撞盒進入邊緣計算，不再假設從觸發中心開始計時。
