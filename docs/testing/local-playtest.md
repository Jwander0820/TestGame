# 本機試玩方式

- 狀態：目前有效
- 最後更新：2026-07-16
- 適用範圍：SPEC-0001 首個可玩垂直切片

## 最短路徑

在檔案總管雙擊專案根目錄的 `play-local.cmd`，或於 PowerShell 執行：

```powershell
cd C:\codex\Game
.\play-local.cmd
```

啟動訊息出現後，以瀏覽器開啟 `http://localhost:5173`。終端機必須保持開啟；試玩結束後在終端機按 `Ctrl+C` 停止伺服器。

啟動器依序使用：

1. 符合版本需求的系統 Node.js 與 npm。
2. 本機 Codex 內建的 Node.js 與 pnpm 執行環境。
3. 兩者皆不存在時，顯示 Node.js LTS 安裝提示並結束。

啟動器也會檢查專案套件：若 `node_modules` 尚未準備，正常啟動時會先安裝本專案所需套件，再啟動遊戲。使用系統 npm 時不建立額外的 `package-lock.json`；使用 Codex runtime 時依 `pnpm-lock.yaml` 安裝。

因此在目前的 Codex 桌面環境中，不一定需要先安裝 Node.js，也不需要安裝全域 `pnpm`。若要離開 Codex 環境自行長期開發，仍建議安裝 Node.js LTS；專案需要 Node.js `^20.19.0` 或 `>=22.12.0`。

## 只檢查、不啟動

若想先確認環境是否可用，不啟動伺服器也不自動安裝套件：

```powershell
.\play-local.cmd --check
```

輸出 `Launcher is ready` 代表 Node.js 與專案套件均可用。若顯示套件缺失，改為正常執行 `play-local.cmd`，啟動器就會進行安裝。

## 手動啟動

已安裝 Node.js 時，不需另外安裝全域 pnpm：

```powershell
cd C:\codex\Game
npm run dev
```

若已自行安裝 pnpm，也可執行：

```powershell
pnpm dev
```

## 操作

- 桌面移動：方向鍵或 `A`／`D`。
- 桌面跳躍：空白鍵、`W` 或上方向鍵。
- 暫停／繼續：`Escape` 或畫面暫停按鈕。
- 手機：畫面上的左、右、跳躍三鍵。
- 手機以橫向為主要體驗；保持直向時，16:9 舞台仍可在上方操作，觸控鍵排列於舞台下方。

## 目前試玩重點

- 觀察同一阻礙死亡第 2／3／5／7 次時，遊戲是否依序介入。
- 確認死亡、援助與 checkpoint 在重新整理後仍保留。
- 原地不動約 8 秒，確認等待彩蛋只完整觸發一次。
- 起點先往左移動並連續跳上頁邊的兩層紅框膠帶，確認 8 枚標示「0」的金幣只完整吐槽一次。
- 使用暫停選單測試重來、靜音與清除紀錄二次確認。

## 常見問題

### 找不到 `pnpm` 或 `pnpm.cmd`

直接改用 `play-local.cmd`。啟動器不要求全域 pnpm。

### `localhost:5173` 無法開啟

先確認啟動終端機仍在執行。若 5173 已被其他程式使用，Vite 會在終端機顯示實際採用的下一個連接埠，請開啟該網址。

### 安裝 Node.js 後仍找不到 `node`

關閉目前 PowerShell，再開啟新視窗，執行 `node -v` 與 `npm -v` 確認環境變數已重新載入。

### 顯示 Node.js 版本過舊

專案接受 Node.js 20.19 以上的 20.x，或 Node.js 22.12 以上版本。建議直接安裝官網目前的 LTS 版本；安裝後關閉並重開終端機。

### 第一次啟動停在安裝套件

第一次執行可能需要下載 Phaser、Vite 與 TypeScript 等專案套件，時間依網路而定。套件只會放在本專案的 `node_modules`，不會上傳專案或安裝全域 pnpm。若安裝失敗，確認網路後再次執行即可。
